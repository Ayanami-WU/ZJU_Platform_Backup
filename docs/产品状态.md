## 跨业务差距

活动的桌面卡片、移动卡片、桌面列表和详情显示日期年份。生命周期判断先验证开始、结束时间及年月日，无效日期显示未知，不推断为已结束；移动端不为无效日期生成星期。本地 7 项隔离浏览器检查覆盖中英文、日夜主题、桌面/移动视口、列表、跨年详情及正常状态回归，未修改活动正文、报名或排序规则。

公开 `/api/settings` 仅返回明确列出的展示字段；联系信息、邀请码、未知键和旧赛事配置不再随公共响应返回，赛事仍使用专用接口。后台读取迁到 `/api/admin/settings`，平台管理员读取支持的编辑项，页面运营仅读取原有页面管理范围；响应禁止存储，Service Worker 对 settings 使用 NetworkOnly。本地 HTTP/JWT/SQLite 已验证各角色边界，尚未完成全部个人信息接口审计。

Docker 使用 Node.js 22，补齐构建依赖和 dist/server/shared；Compose 对齐 SECRET_KEY、DATABASE_FILE、5180/5181 及持久化卷。备份命令复用一致性快照工具，失效图片批处理入口已移除。容器构建、健康、开发代理、重建保留数据和备份已纳入发布前 CI，运行方式见[容器运行与备份](操作手册/容器运行与备份.md)。

开发入口统一固定 5180/5181 并关闭后台任务，任一进程退出时停止另一进程；Makefile 使用现有 npm/Compose 命令，本地 Playwright 继承本地服务配置。环境样例移除未消费选项和可直接使用的口令，演示重置必须显式提供密码。现网发布使用正常依赖锁校验，并合并旧 CORS 别名、移除历史 IP、补齐正式 Web/iOS 来源；环境文件更新可重复执行、原子替换，保留自定义客户端及数据库、端口、密钥，失败沿用发布恢复流程。

Capacitor core/ios/cli 固定为 8.5.3，锁文件与 Swift Package 已同步；不带 legacy-peer-deps 的安装、Web 构建和 Windows 上的 cap sync ios 已通过，Xcode 编译、签名及真机仍需对应平台验收。

登录弹窗打开后聚焦首个输入框，Tab/Shift+Tab 限于弹窗内，Esc、关闭按钮和遮罩关闭后恢复到触发控件；程序化打开保留原焦点返回。页面 viewport 允许缩放。本地浏览器已验证桌面/移动视口和日夜主题，以及 2 倍页面缩放、放大文字、注册动态字段与超时回归；真实手机双指手势仍需真机验收。

robots.txt、静态 sitemap 和 SEO 无浏览器环境的域名回退统一使用 `tuotuzju.com`。静态 sitemap 移除无法核实内容更新时间的旧 lastmod，待有可靠来源后再填写；不以构建日期替代页面内容修改日期。
